Neon Coast Cover Studio — a web app that turns your photos and a caption into multi-panel GTA 6-style cover art, with a Vice City sunset / neon colour grade, and exports it as a PNG in the common post sizes (1080 x 1080, 1080 x 1350, 1920 x 1080). Runs offline in a desktop browser from its own static files; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
